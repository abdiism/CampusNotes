### Getting Started

#### Prerequisites

This project requires the following dependencies:
*   **Programming Language:** JavaScript
*   **Package Manager:** Npm

#### Installation

Build CampusNotes from the source and install dependencies:

1.  **Clone the repository:**
    ```sh
    git clone https://github.com/abdiism/CampusNotes
    ```

2.  **Navigate to the project directory:**
    ```sh
    cd CampusNotes
    ```

3.  **Install the dependencies:**
    Using `npm`:
    ```sh
    npm install
    ```

#### Usage

Run the project with:

Using `npm`:
```sh
npm start
